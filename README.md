This is a simple and interactive **Quiz App** built using **React.js**. It allows users to take a quiz, view their score instantly, and is designed with a clean, minimal interface. This is my **second small project** as part of my React learning journey.

---

## ✨ Features

- ✅ Multiple-choice quiz functionality
- 🧠 Real-time score tracking
- 🎨 Simple and responsive UI
- ⚛️ Built with React functional components and hooks (useState)
- 📁 Component-based architecture for better code organization
